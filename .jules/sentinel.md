## 2024-05-24 - Argument Injection and Shell Globbing in Bash Scripts
**Vulnerability:** Shell scripts processing user input via environment variables (`EXTRA_PACKAGES`, `NPM_PACKAGES`) were vulnerable to argument injection attacks because they didn't separate arguments from package names using `--`. Additionally, iterating over strings without using proper bash arrays and `read -r -a` can cause unexpected shell globbing behavior.
**Learning:** When writing bash scripts that install packages using tools like `pacman`, `yay`, or `npm`, always use `--` to indicate the end of command options. If the user passes `-h` or `--help` as a package name, the package manager might execute the option instead of installing a package. In addition, when parsing space-separated variables, tabs, carriage returns, and newlines must be sanitized before parsing the array, to prevent shell globbing and parse string cleanly.
**Prevention:** Always use `local -a array_name=(); read -r -a array_name <<< "${VAR_NAME//[$'\t\r\n']/ }"` to parse variables safely. Always use `command -option -- "$variable"` syntax when providing variable strings as arguments to a command. Check for empty variables `[ -z "$variable" ] && continue` before processing to prevent edge-case failures.
